🗑️ 几秒内批量删除 ChatGPT 对话。选择全部或挑选特定聊天 — 一键全部删除。

厌倦了逐条删除 ChatGPT 聊天记录？ChatGPT Chat Cleaner 在 ChatGPT 侧边栏中直接添加选择模式，让你一次标记多个对话并批量删除。非常适合整理聊天历史、清理旧对话。

使用方法
————————

1. 打开 chatgpt.com
2. 点击屏幕右边缘的小标签 — 或按下 Ctrl+Shift+X（Mac 上为 Cmd+Shift+X）进入选择模式
3. 点击聊天进行选择，或按住 Shift 并悬停鼠标一次选中多个
4. 按 Enter 确认（确认 → 再次按 Enter），或点击删除按钮，一次性移除所有已选内容

⌨️ 键盘快捷键
——————————

• Ctrl+Shift+X / Cmd+Shift+X — 进入 / 退出选择模式
• 点击 — 切换聊天选中状态
• Shift + 悬停 — 一次选中多个聊天
• Ctrl+A / Cmd+A — 选择所有聊天
• Ctrl+D / Cmd+D — 清除选择
• Enter → Enter — 删除已选项目（两步确认）
• Escape — 退出选择模式

🔒 隐私说明
————————

ChatGPT Chat Cleaner 不收集、存储或传输任何个人数据。扩展程序仅代表你直接向 ChatGPT 自身的 API 发送删除请求 — 与你手动删除聊天时 ChatGPT 执行的请求完全相同。
