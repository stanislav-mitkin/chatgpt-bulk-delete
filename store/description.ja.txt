🗑️ ChatGPTの会話を数秒で一括削除。すべて選択するか、削除したいチャットを選んで — ワンクリックでまとめて削除できます。

ChatGPTのチャットをひとつずつ削除するのは面倒ではありませんか？ChatGPT Chat Cleaner は、ChatGPTのサイドバーに選択モードを追加します。複数の会話をまとめてマークして、一度に削除できます。履歴の整理や古いチャットの一括削除に最適です。

使い方
——————

1. chatgpt.com を開く
2. サイドバーの「Select chats」ボタンをクリック — または Ctrl+Shift+K（MacはCmd+Shift+K）を押す
3. チャットにカーソルを合わせてスペースキーを押すか、会話をクリックして選択する
4. Enter キーを押して確認（確認 → もう一度 Enter）するか、「削除」ボタンをクリックする

⌨️ キーボードショートカット
————————————————————————

• Ctrl+Shift+K / Cmd+Shift+K — 選択モードの開始 / 終了
• スペース — カーソル下のチャットの選択を切り替える
• Ctrl+A / Cmd+A — すべてのチャットを選択
• Ctrl+D / Cmd+D — 選択をクリア
• Enter → Enter — 選択したチャットを削除（2段階確認）
• Escape — 選択モードを終了

✨ 機能
——————

✓ 何件でも会話をまとめて選択・削除
✓ ショートカット1つですべてを選択
✓ 2段階の削除確認 — 誤削除を防止
✓ キーボードだけで完結するワークフロー
✓ chatgpt.com と chat.openai.com の両方に対応
✓ 軽量 — バックグラウンドスクリプトなし、外部サーバーへの通信なし
✓ アカウント不要、ログイン不要、データ収集なし

🔒 プライバシー
——————————

ChatGPT Chat Cleaner は個人データを一切収集・保存・送信しません。拡張機能はあなたの代わりに、ChatGPT自身のAPIへ削除リクエストを直接送信するだけです。これは、チャットを手動で削除するときにChatGPTが行うリクエストとまったく同じです。
