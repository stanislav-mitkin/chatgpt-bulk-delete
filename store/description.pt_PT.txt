🗑️ Elimina conversas do ChatGPT em massa, em segundos. Seleciona tudo ou escolhe os chats — e apaga-os com um único clique.

Farto de eliminar chats do ChatGPT um a um? O ChatGPT Chat Cleaner adiciona um modo de seleção diretamente na barra lateral do ChatGPT para poderes marcar várias conversas e eliminá-las todas de uma vez. Ideal para organizar o teu histórico e limpar conversas antigas.

COMO FUNCIONA
—————————————

1. Abre chatgpt.com
2. Clica no pequeno separador na margem direita do ecrã — ou prime Ctrl+Shift+X (Cmd+Shift+X no Mac) — para entrar no modo de seleção
3. Clica nos chats para os selecionar, ou mantém Shift premido e passa o cursor para selecionar vários de uma vez
4. Prime Enter (confirma → Enter novamente) ou clica em Eliminar para remover tudo

⌨️ ATALHOS DE TECLADO
——————————————————

• Ctrl+Shift+X / Cmd+Shift+X — Entrar / sair do modo de seleção
• Clique — Alternar seleção do chat
• Shift + passar o cursor — Selecionar vários chats de uma vez
• Ctrl+A / Cmd+A — Selecionar todos os chats
• Ctrl+D / Cmd+D — Limpar seleção
• Enter → Enter — Eliminar selecionados (confirmação em dois passos)
• Escape — Sair do modo de seleção

✨ FUNCIONALIDADES
———————————————

✓ Seleção e eliminação em massa de qualquer número de conversas
✓ Seleção múltipla com Shift + passar o cursor para escolher vários chats rapidamente
✓ Selecionar tudo com um único atalho
✓ Confirmação de eliminação em dois passos — sem eliminações acidentais
✓ Mensagem clara "N chats eliminados" no final
✓ Fluxo de trabalho totalmente pelo teclado
✓ Funciona em chatgpt.com e em chat.openai.com
✓ Leve — sem scripts em segundo plano, sem chamadas a servidores de terceiros
✓ Sem conta, sem início de sessão, sem recolha de dados

🔒 PRIVACIDADE
———————————

O ChatGPT Chat Cleaner não recolhe, armazena nem transmite quaisquer dados pessoais. A extensão apenas envia pedidos de eliminação diretamente para a própria API do ChatGPT em teu nome — os mesmos pedidos que o ChatGPT realiza quando eliminas um chat manualmente.
