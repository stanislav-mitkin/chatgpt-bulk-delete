🗑️ 幾秒內批次刪除 ChatGPT 對話。選擇全部或挑選特定聊天 — 一鍵全部刪除。

厭倦了逐條刪除 ChatGPT 聊天記錄？ChatGPT Chat Cleaner 在 ChatGPT 側邊欄中直接新增選取模式，讓你一次標記多個對話並批次刪除。非常適合整理聊天歷史、清理舊對話。

使用方法
————————

1. 開啟 chatgpt.com
2. 點選側邊欄中的「Select chats」按鈕 — 或按下 Ctrl+Shift+K（Mac 上為 Cmd+Shift+K）
3. 將滑鼠懸停在聊天上並按空白鍵，或直接點選對話進行選取
4. 按 Enter 確認（確認 → 再次按 Enter），或點選刪除按鈕，一次移除所有已選內容

⌨️ 鍵盤快捷鍵
——————————

• Ctrl+Shift+K / Cmd+Shift+K — 進入 / 離開選取模式
• 空白鍵 — 切換游標下方聊天的選取狀態
• Ctrl+A / Cmd+A — 選取所有聊天
• Ctrl+D / Cmd+D — 清除選取
• Enter → Enter — 刪除已選項目（兩步確認）
• Escape — 離開選取模式

🔒 隱私說明
————————

ChatGPT Chat Cleaner 不收集、儲存或傳輸任何個人資料。擴充功能僅代表你直接向 ChatGPT 自身的 API 發送刪除請求 — 與你手動刪除聊天時 ChatGPT 執行的請求完全相同。
