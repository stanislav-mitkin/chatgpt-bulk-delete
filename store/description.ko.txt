🗑️ ChatGPT 대화를 몇 초 만에 일괄 삭제하세요. 전체 선택하거나 원하는 채팅만 골라 — 한 번의 클릭으로 모두 삭제할 수 있습니다.

ChatGPT 채팅을 하나씩 삭제하는 게 번거롭지 않으신가요? ChatGPT Chat Cleaner는 ChatGPT 사이드바에 선택 모드를 추가하여 여러 대화를 한꺼번에 선택하고 일괄 삭제할 수 있게 해줍니다. 대화 기록을 정리하고 오래된 채팅을 깔끔하게 지우는 데 딱입니다.

사용 방법
—————————

1. chatgpt.com 열기
2. 화면 오른쪽 가장자리의 작은 탭 클릭 — 또는 Ctrl+Shift+X 누르기 (Mac은 Cmd+Shift+X)로 선택 모드 진입
3. 채팅을 클릭하여 선택하거나, Shift를 누른 채 마우스를 올려 여러 개를 한 번에 선택
4. Enter 키를 눌러 확인 (확인 → 다시 Enter) 하거나 삭제 버튼 클릭

⌨️ 키보드 단축키
————————————

• Ctrl+Shift+X / Cmd+Shift+X — 선택 모드 시작 / 종료
• 클릭 — 채팅 선택 전환
• Shift + 마우스 오버 — 여러 채팅 한 번에 선택
• Ctrl+A / Cmd+A — 모든 채팅 선택
• Ctrl+D / Cmd+D — 선택 초기화
• Enter → Enter — 선택한 항목 삭제 (2단계 확인)
• Escape — 선택 모드 종료

✨ 주요 기능
—————————

✓ 원하는 수만큼 대화를 선택하여 일괄 삭제
✓ Shift + 마우스 오버로 여러 채팅을 빠르게 선택
✓ 단축키 하나로 전체 선택
✓ 2단계 삭제 확인 — 실수로 삭제되는 일 없음
✓ 완료 후 "N개 채팅 삭제됨" 명확한 결과 메시지
✓ 키보드만으로 완결되는 워크플로우
✓ chatgpt.com 및 chat.openai.com 모두 지원
✓ 가벼움 — 백그라운드 스크립트 없음, 외부 서버 연결 없음
✓ 계정 불필요, 로그인 불필요, 데이터 수집 없음

🔒 개인정보 보호
—————————————

ChatGPT Chat Cleaner는 개인 데이터를 수집, 저장 또는 전송하지 않습니다. 이 확장 프로그램은 사용자를 대신하여 ChatGPT의 자체 API에 삭제 요청을 직접 전송할 뿐입니다 — 채팅을 수동으로 삭제할 때 ChatGPT가 수행하는 것과 동일한 요청입니다.
