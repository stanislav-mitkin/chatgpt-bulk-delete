## Full description

**Tired of deleting ChatGPT conversations one at a time?**

ChatGPT Chat Cleaner adds a fast, keyboard-friendly selection mode directly into the ChatGPT sidebar. Pick any number of chats, then delete them all with a single confirmation — no page reloads, no extra clicks.

---

### How it works

1. Open [chatgpt.com](https://chatgpt.com) in Chrome.
2. A small tab appears at the right edge of the screen.
3. Click it (or press **Ctrl+Shift+X** / **⌘⇧X** on Mac) to enter Selection mode.
4. Click any conversation in the sidebar to toggle it, or hold **Shift** and hover to brush-select several at once. **Ctrl+A** / **⌘A** selects all.
5. Press **Enter** (confirm with a second press), or click the **Delete** button — done.

---

### Features

- **Bulk delete** — remove dozens or hundreds of chats in one action
- **Brush-select** — hold Shift and hover to select several chats at once, no clicking each one
- **Select all** — Ctrl+A / ⌘A highlights every visible conversation instantly
- **Keyboard-first** — full workflow without touching the mouse: select, confirm, delete
- **Click to toggle** — click individual chats to add or remove them from the selection
- **Progress bar + result message** — live feedback while deleting, then a clear "Deleted N chats" summary
- **Double-confirm** — a second keypress (or button click) is required before anything is deleted, so accidental wipes are impossible
- **Scoped highlight** — only the chat list itself is highlighted while active, not the whole sidebar
- **Dark & light theme** — automatically matches ChatGPT's current theme
- **18 languages** — UI adapts to your browser locale (English, Russian, German, French, Spanish, Portuguese, Italian, Polish, Dutch, Turkish, Arabic, Chinese Simplified/Traditional, Japanese, Korean, Indonesian, Vietnamese)
- **Zero tracking** — no analytics, no telemetry, no remote servers; all logic runs locally in the page

---

### Keyboard shortcuts

| Key | Action |
|---|---|
| Ctrl+Shift+X / ⌘⇧X | Toggle Selection mode on/off |
| Click | Toggle a chat |
| Shift + hover | Brush-select multiple chats |
| Ctrl+A / ⌘A | Select all chats |
| Ctrl+D / ⌘D | Clear selection |
| Enter × 2 | Confirm and delete |
| Esc | Exit Selection mode |

---

### Privacy

The extension runs entirely within your browser tab. It calls ChatGPT's own API endpoints — the same ones the website uses — using your existing login session. No data ever leaves your browser to any third-party server.

**Permissions requested:**
- `chatgpt.com` — required to read the sidebar and call the delete API
